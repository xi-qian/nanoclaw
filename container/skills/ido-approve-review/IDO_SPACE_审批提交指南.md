# IDO SPACE 审批提交指南

> **版本**：v2.0 | **编制日期**：2026-05-27
> 本文档按三类审批的实际表单字段，逐项说明填写要点和提交注意事项，帮助提交人减少驳回和来回修改。

---

## 一、付款审批

**表单字段及填写要点**：

| # | 字段 | 类型 | 填写要点 |
|---|------|------|---------|
| 1 | **主题** | input | 使用「付XXX款」格式，如「付2026年Q1医科中心网络费（1、2、3月）」，标明费用归属期间 |
| 2 | **金额（元）** | amount | 含税总金额，确认大写与小写一致 |
| 3 | **申请类型** | radioV2 | 三选一，按实际情况选择：<br>• **应付款**：已收到发票、款项未付 → 需上传双章合同 + 发票<br>• **预付款**：未收到发票、预先支付 → 需上传双章合同<br>• **备用金**：临时拆借给个人的款项 → 需写明借款事由及明细 |
| 4 | **所属项目** | checkboxV2 | 必须选具体项目编号，不可仅选「其他」<br>人数据支出（见下文）选「其他」将被**直接驳回** |
| 5 | **是否有合同** | radioV2 | • 选「有」→ 必须关联合同审批实例<br>• 选「无」但附件有双章合同 → 在备注说明无法关联的原因（如经办人离职） |
| 6 | **设备付款** | radioV2 | 如为设备购置付款选「是」，需上传设备验收单 |
| 7 | **付款物料到货时间** | textarea | 选填；设备或物料付款时填写到货日期 |
| 8 | **资金预算** | fieldList | 填写三项：①使用部门 ②预算科目（如「5.2经营费用常规-服务费」）③预算金额<br>预算科目必须与费用性质匹配，预算金额须覆盖本次付款 |
| 9 | **付款账户** | radioV2 | 选择正确的付款主体（如「北京荷塘生华-工行」） |
| 10 | **付款方式** | radioV2 | 选「网银」或「银行转账」 |
| 11 | **收款单位名称/开户行及账号** | textarea | 完整填写：名称、税号、地址电话、开户行、账号<br>必须与发票收款方完全一致 |
| 12 | **备注** | textarea | 填写特殊情况说明：合同无法关联原因、价格差异说明、已确认事项声明等<br>**不要**仅写「请领导审批」 |
| 13 | **附件** | attachmentV2 | 见下表 |

**附件要求**：

| 申请类型 | 必须上传 | 建议上传 |
|----------|---------|---------|
| 应付款 | 双章合同 PDF、发票 | 验收/交付证明、对账单 |
| 预付款 | 双章合同 PDF | 报价单 |
| 备用金 | 借款事由说明 | — |

## 二、合同审批

**表单字段及填写要点**：

| # | 字段 | 类型 | 填写要点 |
|---|------|------|---------|
| 1 | **主题** | input | 简明扼要，如「采购合同-XX公司-XX元」 |
| 2 | **盖章类型** | radioV2 | 选「公章」或「合同专用章」 |
| 3 | **合同模板** | radioV2 | **优先使用公司标准合同模板**；选「否/无」的，须在目的字段说明理由 |
| 4 | **合同类型** | radioV2 | 按实际选择（采购类/服务类/合作类/保密协议等） |
| 5 | **目的** | textarea | **必填**：写明合同的业务目的，关联到具体项目、管线或业务场景（审查中对应「场景归因」判断） |
| 6 | **合同编号** | input | 有合同编号时填写；暂无则填「无」 |
| 7 | **对方单位名称** | input | 完整公司名称，与营业执照一致 |
| 8 | **对方负责人** | input | 对方签约人姓名 |
| 9 | **金额** | amount | 合同总金额（含税） |
| 10 | **关联采购申请** | — | 若合同对应已有的采购审批单，**必须关联**（未关联会被要求补关联） |
| 11 | **备注** | textarea | 填写付款条款摘要（如「月结」「100%预付款」「分期」）、特殊条款说明等 |
| 12 | **附件** | attachmentV2 | 见下表 |

**附件要求**：

| 附件 | 必须 | 说明 |
|------|:---:|------|
| 合同草案/正文 | **必须** | 含双方主体、金额、付款条款、违约责任、验收标准 |
| 双章扫描件 | 建议 | 线下签署时提供 |
| 对方营业执照/经营资质 | 建议 | 新供应商或首次合作时提供（审查中对应「真实性-主体资质」检查） |
| 报价单/技术协议 | 建议 | 有技术标的时提供，用于核验金额和标的匹配 |

## 三、采购审批

**表单字段及填写要点**：

| # | 字段 | 类型 | 填写要点 |
|---|------|------|---------|
| 1 | **主题** | input | 简明扼要，如「细胞培养耗材采购」 |
| 2 | **采购类型** | radioV2 | 选「生产原料」「设备」或「其他」 |
| 3 | **申请公司** | input | 填写申请主体公司名称 |
| 4 | **采购总金额** | amount | 含税总金额，确认大写与小写一致 |
| 5 | **物料供应商信息** | radioV2 | **优先选「合格供应商」**；选「临时合格供应商」时，必须在备注说明原因 |
| 6 | **是否使用我公司合同模板** | radioV2 | 选「是」优先；选「否」需在备注说明原因 |
| 7 | **上传采购明细** | attachmentV2 | **必须上传 Excel**，列明：物品名称、货号、数量、单价、建议供应商 |
| 8 | **所属项目** | checkboxV2 | 必须选具体项目编号；人数据相关采购不可选「其他」 |
| 9 | **备注** | textarea | 填写价格偏离说明、供应商选型理由、合同模板不适用原因等 |

**供应商选择规则**：
- **优先合格供应商库内供应商**（见供应商主表）
- 库外供应商需有历史合作记录，并在备注说明选型理由
- GMP 生产物料：供应商必须在合格库内且通过 GMP 审计

**比价规则**：

| 采购金额 | 比价要求 |
|----------|---------|
| ≤ ¥5,000 | 免比价 |
| > ¥5,000 | 与历史采购均价对比，偏离超 30% 需在备注说明 |
| 首次采购 | 标注「首次采购，无历史参照」 |

## 通用注意事项

### 人数据支出项目关联（三类审批通用）

凡涉及以下关键词的支出，**所属项目不得为「其他」**：

> 采集、检测、测序、组学（蛋白/基因/代谢/转录）、样本、受试者、患者、临床数据、生物标志物、单采血、PBMC、血清、血浆

**原因**：人数据是证据资产的核心组成，无项目关联则数据无法追溯和归档。

### 备注填写建议

- 特殊情况说明：合同无法关联原因、价格偏离原因、供应商选择理由
- 已确认事项声明：如「合同公司名称已核对无误」「发票金额已核实」
- **备注是审批人和 AI 审查了解情况的关键渠道**，信息越充分，通过越顺利

### 常见驳回原因及避免方法

| 驳回原因 | 涉及类型 | 如何避免 |
|---------|---------|---------|
| 人数据支出项目为「其他」 | 三类通用 | 关联具体项目编号 |
| 表单「有合同」但未关联审批实例 | 付款 | 确保关联或选「无」+上传合同+备注说明 |
| 供应商不在合格库且无说明 | 采购 | 首选库内供应商，或备注说明选型理由 |
| 价格偏离超 30% 无解释 | 采购 | 备注说明偏离原因（规格差异、涨价、折扣等） |
| 附件缺发票 | 付款(应付款) | 上传对应发票 |
| 附件缺双章合同 | 付款(预付款) | 上传双章合同 PDF |
| 收款方信息与发票不一致 | 付款 | 逐项核对名称、税号、账号 |
| 预算科目与费用性质不匹配 | 付款 | 确认预算科目选对 |
| 非标准合同模板无法务确认 | 合同 | 提交前请法务预审 |
| 采购明细缺物品单价或货号 | 采购 | Excel 中逐项列全 |
