# IDO SPACE 采购审批 Agent 执行标准

> **版本**：v1.2 | **编制日期**：2026-05-26
> **依据**：《付款审批 Agent 工作逻辑报告》《合同审批 Agent 工作逻辑报告》《付款审批 Agent 五项判断整合规则》及 6 笔待审批采购实例验证
> **定位**：本标准是《付款与合同审批 Agent 执行标准 v1.2》的平行标准，专门覆盖**采购申请**（approval_code: `F753B844-865B-4B3D-B44A-544F3178F8F1`）的审批判断

## 一、总则

### 1.1 适用范围

本标准规定 IDO SPACE 采购审批 Agent 在执行采购申请审批判断时必须遵循的**输出格式、判断准则、数据方法、证据要求和表述规范**。所有采购审批建议卡在交付审批人之前，必须通过本标准的合规检查。

**采购审批与付款/合同审批的核心差异**：

| 维度 | 付款/合同审批 | 采购审批 |
|-|-|-|
| 核心问题 | "要不要付""能不能签" | "要不要买""向谁买""贵不贵" |
| 合同关系 | 通常有合同约束付款节点 | 采购申请阶段通常无合同 |
| 价格判断 | 与合同约定金额比对 | 与历史采购均价比对（核心能力） |
| 供应商评估 | 供应商主数据、信用、履约记录 | 合格供应商库优先判定 + 历史合作频次补充 |
| 核心证据 | 合同、发票、验收单、银行回单 | 采购明细 Excel（物品、货号、数量、单价、建议供应商） |
| 金额性质 | 已确定的对外支付金额 | 申请采购预算，实际支付在后续付款审批中 |

### 1.2 核心原则

| 原则 | 说明 |
|-|-|
| **判断可追溯** | 每个结论必须附带信息来源或标注「待确认」 |
| **价格有基准** | 凡涉及价格判断，必须与历史采购均价对比；无历史记录时标注「首次采购，无参照基准」，禁止断言「价格合理」 |
| **偏离有阈值** | 价格偏离历史均价超过 30%，必须标注「价格偏离」并在条件中要求确认比价 |
| **小额豁免** | 采购总金额 ≤ ¥5,000 时，不执行比价检查；价格偏离不做为条件通过的判断依据，直接标注「小额采购（¥X ≤ ¥5,000），免比价」 |
| **供应商有分层** | 供应商评价优先依据合格供应商库，库内直接认定合格；库外再以历史合作频次推断，不使用主观评价 |
| **条件可关闭** | 「条件通过」的条件必须包含四要素：内容 + 责任人 + 截止时间 + 逾期处理 |
| **证据集中管理** | 同一证据点可以影响多个判断，但应先集中列出再由五项判断分别解释影响 |

### 1.3 禁止表述清单

以下是采购审批 Agent 在建议卡中**禁止出现**的表述及其替代方案：

| 禁止表述 | 原因 | 替代表述 |
|-|-|-|
| 「价格合理」 | 无参照基准 | 「本次单价¥X，较同物品历史均价¥Y偏离 Z%，在/超出阈值」或「首次采购，无参照基准，建议确认比价」 |
| 「金额较小」 | 无标准依据 | 「按公司阈值标准属『极小』级别（¥X ∈ < ¥10,000）」 |
| 「供应商可靠」 | 无量化依据 | 「合格供应商库内供应商（覆盖{N}种物料类别）」或「库外供应商，历史合作 N 次，最近一次采购为 {流水号}」 |
| 「不需要比价」 | Agent 无权决定 | 「截至审批时点，未发现同类采购有比价记录，**建议采购确认**」 |
| 「价格偏高/偏低」 | 无参照基准 | 「较历史均价偏离 +X%，超出 30% 阈值，需确认是否为不同规格或品牌」 |
| 「采购合理」 | 笼统不可执行 | 「必要性：N{级别}——{具体依据}」 |
| 「提请关注」 | 不可执行 | 「条件通过——条件：… 责任人：… 截止：… 逾期：…」 |

## 二、六原子认知框架（采购映射）

采购审批 Agent 共用六原子模型，以下是各原子在采购场景中的映射：

| 原子 | 核心问题 | 采购中的作用 |
|-|-|-|
| Facts | 发生了什么？ | 采购类型、物品明细（名称/货号/数量/单价）、总金额、供应商分类、建议供应商、所属项目、申请公司、采购明细附件 |
| Relations | 和谁有关？ | 采购与供应商、项目、部门、历史采购记录、同类物品的价格参照关系 |
| Rules | 受什么约束？ | 采购制度、供应商准入规则（合格/临时合格）、预算规则、GMP 物料要求、比价规则 |
| Logic | 为什么合理？ | 推导买/不买/缓买的后果：不买是否影响生产连续性、项目进度、合同履约 |
| State | 处于什么阶段？ | 项目阶段、库存状态、历史采购周期、供应商合作关系阶段 |
| Goal | 为了什么价值？ | 保生产、保项目、保质量、控成本、维持供应链稳定 |

### 3.2 Excel 附件解析规范

采购明细附件（`attachmentV2`）为 Excel 格式（`.xlsx`），Agent 必须解析并提取以下列：

| 列名（或等价列） | 必须提取 | 说明 |
|-|-|-|
| 物料名称 / `applyorders_product_cName` | 是 | 物品名称，用于历史匹配 |
| 货号 / `applyOrdersDefineCharacter!H01` | 是 | 产品编号，用于精确匹配历史价格 |
| 数量 / `applyorders_qty` / `采购数量` | 是 | 采购数量 |
| 含税单价 / `oriTaxUnitPrice` | 是 | 单价，核心价格指标 |
| 含税金额 / `oriSum` / `含税金额` | 是 | 小计金额 |
| 建议供应商 / `applyorders_vendor_name` | 是 | 实际供应商 |
| 生产厂商 / `applyOrdersDefineCharacter!Shengchan` / `生产厂商` | 否 | 品牌信息 |
| 物料备注 / `applyOrdersDefineCharacter!BZ01` / `规格说明` | 否 | 规格、包装说明 |

**解析步骤**：

1. 定位表头行：查找包含「物料名称」或 `applyorders_product_cName` 的行
2. 建立列映射：将列名映射到标准字段
3. 逐行提取数据：跳过表头行和合计行
4. 汇总校验：各物品含税金额之和应等于表单中的「采购总金额」

### 3.3 合格供应商库

Agent 必须加载公司合格供应商库（`目前荷塘已有供应商情况.xlsx`），用于供应商合规性判断。**合格供应商库是供应商可靠性的优先判定源——在库内的供应商直接认定合格，无需再从历史采购记录推断可靠性。**

**供应商库结构**（4 个 Sheet，共 281 条物料-供应商记录）：

| Sheet | 记录数 | 覆盖范围 |
|-|-|-|
| 原材料 | 102 | 培养基、酶、化学试剂等 |
| 辅料 | 7 | WFI、缓冲液等 |
| 包装材料 | 16 | 小瓶、胶塞、铝塑盖等 |
| 生产耗材 | 160 | 层析填料、过滤器、细胞筛等 |

**每条记录包含**：内部物料名称、供应商物料名称、规格、级别、物料编码、生产商名称、生产地址、经销商名称、经销商地址、质量标准、批准应用的品种/规格。

**供应商库的判断优先级**：

```
供应商判定流程：
  1. 从采购明细 Excel 提取「建议供应商」
  2. 在合格供应商库中精确匹配（经销商名称 / 生产商名称）
  3. 匹配结果：
     ✓ 在库 → 直接认定「合格供应商」，标注库内记录数和覆盖类别
     ✗ 不在库 → 进入历史采购记录推断流程（见 §3.4）
```

**注意事项**：
- 供应商库仅覆盖生产相关物料（原材料、辅料、包装材料、生产耗材），**不覆盖**行政办公、设备维修等非生产采购渠道
- 京东等电商平台是行政采购的通用渠道，不在库内属正常现象，不构成合规风险
- 供应商库的「经销商名称」和「生产商名称」均需匹配，二选一命中即可

### 3.4 预建数据表（核查时直接查表，无需实时解析）

Agent 已从 238 条已审批采购记录中预建三张 CSV 数据表，核查时直接查表即可，**无需每次从 JSON + Excel 实时解析**。三张表位于 `采购/` 目录：

#### 表1：物料均价速查表（`物料均价速查表.csv`）

**用途**：价值性判断的核心参照——查到待审物品的历史均价、最低/最高价、价差异常标注。

| 字段 | 说明 | 核查用法 |
|-|-|-|
| 物料名称 | 原始名称 | 主匹配键（模糊匹配） |
| 货号 | 产品编号 | 精确匹配键（优先） |
| 规格 | 规格说明 | 区分同名称不同规格的物品 |
| 采购次数 | 历史采购次数 | 判断价格基准可靠性（≥3次可靠，1-2次参考，0次新品） |
| 历史均价 | 均价 | 偏离度计算的基准 |
| 最低价 / 最高价 | 价格区间 | 判断本次单价是否在历史范围内 |
| 价差 | 最高-最低 | 0表示价格完全稳定 |
| 有价差 | 是/否 | 快速筛选异常 |
| 价差异常原因 | 文字说明 | 已标注原因（供应商调价/批量折扣/不同规格/电商波动） |
| 最近供应商 | 最近一次采购的供应商 | 判断供应商是否一致 |
| 最近采购日期 | 日期 | 判断价格是否过时（>6个月需谨慎） |
| 最近单价 | 最近一次的单价 | 最接近当前的参考价 |

**聚合键**：`(物料名称, 货号, 规格)` 三键联合——同名称不同规格的物品各自独立计算均价，不会混淆。

**数据覆盖**：359 种物料规格，331 种价格稳定无价差，28 种有价差但全部已合理解释。

**查询流程**：

```
对采购明细中的每个物品：
  1. 优先按「货号」精确匹配
  2. 货号无匹配 → 按「物料名称」模糊匹配
  3. 匹配到 → 读取历史均价、最低/最高价、价差异常原因
  4. 计算偏离度 = (本次单价 - 历史均价) / 历史均价 × 100%
  5. 检查价差异常原因 → 若有标注，在报告中引用说明
  6. 无匹配 → 标注「首次采购，无参照基准」
```

**用途**：合规性判断——快速判断供应商是否在合格供应商库、历史合作频次。

## 四、五项判断标准

### 4.0 五项判断的边界定义

**最简记忆**：真实性看「是不是真的」；合规性看「符不符合规则」；必要性看「不买会不会出事」；价值性看「买得贵不贵」；承受性看「公司买不买得起」。

| 判断项 | 主问题 | 不应混淆为 |
|-|-|-|
| 真实性 | 采购申请对应的物品、数量、价格、供应商是否真实可核验？ | 不是判断价格是否合理 |
| 合规性 | 采购是否满足供应商准入、预算规则和审批制度？ | 不是判断现金流能否承受 |
| 必要性 | 为什么现在要买？不买会不会影响生产、项目或合同履约？ | 不是判断价格是否划算 |
| 价值性 | 价格是否合理？与历史采购相比是否偏离？ | 不是判断现在是否必须买 |
| 承受性 | 企业当前资金安排是否支持本次采购？ | 不是判断预算是否允许 |

> **关键区分**：预算是否允许采购，归合规性；现金流是否扛得住，归承受性。

---

### 4.1 真实性 — 物品、价格、供应商是否真实可核验

**定义**：真实性关注采购申请中的物品信息、价格信息和供应商信息是否可核验、是否与历史记录一致。

**必查项**：
- [ ] 采购明细附件是否完整（Excel 可正常解析）
- [ ] 物品名称、货号、数量、单价是否齐全
- [ ] 各物品含税金额之和是否等于采购总金额
- [ ] 建议供应商是否填写
- [ ] 与历史采购记录做物品和价格交叉核验

**判断层级**：

| 层级 | 判断口径 | 典型表达 |
|-|-|-|
| F1 通过 | 采购明细完整、金额校验一致、供应商可核验、与历史记录匹配 | 真实性：通过｜采购明细附件完整，5项物品名称、货号、数量、单价清晰，金额合计与总金额一致，建议供应商与历史合作供应商一致 |
| F2 基本通过 | 核心事实成立，但存在轻微信息缺口 | 真实性：基本通过｜核心物品信息一致，但附件缺少单价和数量明细，无法完成逐项核验 |
| F3 需确认 | 附件不完整或关键信息缺失 | 真实性：需确认｜已提供采购明细，但缺少货号和单价字段 |
| F4 存疑 | 关键信息冲突（如总金额与明细合计不符） | 真实性：存疑｜明细合计金额与采购总金额存在差异，需要申请人说明 |
| F5 未通过 | 缺少采购明细或存在明显虚假信息 | 真实性：未通过｜无采购明细附件，无法核验物品和价格信息 |

---

### 4.2 合规性 — 供应商准入、预算和审批规则是否允许

**定义**：合规性关注采购申请是否满足供应商准入规则、预算规则和审批制度。

**必查项**：
- [ ] 供应商是否在合格供应商库中（**优先判断**，在库直接认定合格）
- [ ] 供应商分类是否在准入范围内（合格供应商 / 临时合格供应商）
- [ ] 是否使用公司合同模板（涉及合同合规）
- [ ] 采购类型是否与业务用途匹配
- [ ] 申请公司是否正确
- [ ] 审批流程是否正常

**供应商可靠性判定优先级**：

```
判定顺序（从高到低）：
  1. 合格供应商库 → 经销商名称或生产商名称精确匹配
     ✓ 在库 → 直接认定合格，无需历史推断
     ✗ 不在库 → 进入步骤 2
  2. 历史采购频次推断（库外供应商的补充判定）
     高频（≥20次） → 可靠性中高，如京东（202次）、林萘（35次）
     中频（5-19次） → 可靠性中，需关注采购类型
     低频（1-4次） → 可靠性中低，建议确认资质
     无记录 → 新供应商，需确认准入
```

**供应商分类与可靠性等级**：

| 分类 | 判定来源 | 可靠性等级 | 审查强度 |
|-|-|-|-|
| 合格供应商库内 | 供应商库精确匹配 | 高 | 常规审查，无需历史推断 |
| 合格供应商（库外） | 表单标记 + 历史高频（≥20次） | 中高 | 常规审查 |
| 临时合格供应商 | 表单标记 | 中 | 加强审查，关注实际采购渠道 |
| 库外新供应商 | 无库内记录 + 无或低频历史 | 低 | 须确认准入资质和比价 |

**判断层级**：

| 层级 | 判断口径 | 典型表达 |
|-|-|-|
| R1 通过 | 供应商在合格供应商库内，或在库外但历史合作高频，采购类型匹配、审批流程正常 | 合规性：通过｜供应商在合格供应商库内（覆盖{N}种物料），采购类型为"生产原料"，符合业务用途 |
| R2 存在例外 | 供应商不在库内，但表单标记为合格/临时合格，且有历史合作记录支撑 | 合规性：存在例外｜供应商不在合格供应商库内，但历史合作{N}次，标记为{分类}，实际采购渠道为{渠道} |
| R3 规则冲突 | 供应商未准入且无历史记录，或采购类型与用途不匹配 | 合规性：规则冲突｜供应商不在合格供应商库中且无历史合作记录，需先完成供应商准入审核 |
| R4 红线不通过 | 触碰不可豁免规则（如黑名单供应商） | 合规性：未通过｜供应商在黑名单中，不建议审批 |
| R5 无法判断 | 缺少供应商资质或审批制度信息 | 合规性：无法判断｜缺少供应商准入资质信息 |

---

### 4.3 必要性 — 为什么现在要买

**定义**：必要性关注当前采购的紧迫性：如果现在不买，是否会影响生产连续性、项目进度、合同履约或法定义务。

**必要性分层规则**：

| 层级 | 必要性来源 | 判断强度 | 典型表达 |
|-|-|-|-|
| N1 | 法定/监管/强制义务 | 很强 | 必要性：高｜过滤器更换为客户合同约定义务，不更换将影响合同履约和洁净环境维护 |
| N2 | 合同到期履约义务 | 很强 | 必要性：高｜采购由客户合同约定驱动，不执行将影响合同履约 |
| N3 | 已发生业务事实（库存耗尽） | 强 | 必要性：中高｜PBS为持续消耗品，当前库存已低，需及时补充 |
| N4 | 业务连续性/生产需求 | 强 | 必要性：高｜离心管和培养瓶为细胞培养核心耗材，不补充将影响生产连续性 |
| N5 | 内部批准/计划内安排 | 中 | 必要性：中｜办公用品采购属计划内行政安排，但必要性强度一般 |
| N6 | 仅申请人主张 | 弱 | 必要性：支撑不足｜当前仅有申请人说明，缺少项目关联或消耗依据 |
| N7 | 无依据 | 不成立 | 必要性：无法判断｜缺少采购触发依据，建议补充材料 |

**按采购类型的必要性判断**：

| 采购类型 | 默认必要性强度 | 判断依据 |
|-|-|-|
| 生产原料 | 强（N3-N4） | 消耗品，有历史采购周期可参照 |
| 设备 | 中强（N2-N4） | 需关联项目，说明设备用途 |
| 其他 | 中（N5-N6） | 行政/办公用品，需确认计划内安排 |

---

### 4.4 价值性 — 价格是否合理

**定义**：价值性关注采购价格是否合理，核心方法是**与历史采购均价对比**。这是采购审批区别于付款/合同审批的核心判断维度。

**价值性分层规则**：

| 层级 | 价格状态 | 判断强度 | 典型表达 |
|-|-|-|-|
| V0 | 小额采购免比价（总额 ≤ ¥5,000） | 豁免 | 价值性：免比价｜小额采购（¥X ≤ ¥5,000），按规则免比价检查 |
| V1 | 价格低于历史均价（节省成本） | 很强 | 价值性：优｜本次单价较历史均价低 X%，价格更优 |
| V2 | 价格与历史完全一致 | 强 | 价值性：合理｜全部 N 项物品单价与历史完全一致（0.0% 偏离） |
| V3 | 价格小幅偏离历史（≤30%） | 中 | 价值性：基本合理｜核心规格价格一致，新增规格单价低于对应大规格，差异合理 |
| V4 | 首次采购，无历史记录 | 中（需确认） | 价值性：待确认｜首次采购该物品，无历史参照基准，建议确认比价 |
| V5 | 价格偏离历史 30%-50% | 弱 | 价值性：偏离｜单价较历史均价偏离 X%，超出 30% 阈值，需确认比价依据 |
| V6 | 价格偏离超 50% | 很弱 | 价值性：严重偏离｜单价较历史均价偏离 X%，需采购部门专项确认 |
| V7 | 无价格信息 | 无法判断 | 价值性：无法判断｜附件缺少单价信息，无法完成价格核验 |
| V8 | 明显不合理 | 不成立 | 价值性：不成立｜价格显著高于市场价和历史均价，无合理解释 |

**价格偏离计算与处理规则**：

```
采购总金额 ≤ ¥5,000 → 免比价，直接标注「小额采购免比价」，跳过以下偏离计算
采购总金额 > ¥5,000 → 执行以下规则：

偏离度 = (本次单价 - 历史均价) / 历史均价 × 100%

处理规则：
  |偏离度| ≤ 10%   → 正常，标注「一致」或「基本一致」
  10% < |偏离度| ≤ 30% → 轻微偏离，标注偏离值，但无需额外确认
  30% < |偏离度| ≤ 50% → 中度偏离，必须在条件中要求确认比价依据
  |偏离度| > 50%  → 严重偏离，升级采购部门确认，建议人工审查
```

**新品首次采购的处理规范**：
- **采购总金额 ≤ ¥5,000**：免比价，标注「小额采购免比价」
- 采购总金额 > ¥5,000 时：
  - **禁止**在无参照基准的情况下断言「价格合理」
  - 首次采购物品必须标注「首次采购，无历史参照基准」
  - 若物品金额占采购总金额 > 50%，建议确认至少 2 家供应商比价
  - 后续同类采购将建立价格基准

**不同规格物品的价格对比**：
- 同名称不同规格的物品（如不同尺寸的过滤器），不能直接比价
- 应按「同货号精确匹配」优先，「同名称匹配」次之
- 不同规格的价格对比需说明规格差异

### 4.5 承受性 — 公司买不买得起

**定义**：与付款审批承受性相同，判断企业当前资金安排是否支持本次采购。承受性只看资金计划与现金流。

**判断层级**：（与 v1.2 标准 §4.5 一致）

| 层级 | 承受状态 | 判断口径 | 典型表达 |
|-|-|-|-|
| C1 | 可承受 | 采购金额属"极小"或"小"级别，无需特别关注 | 承受性：可承受｜本次采购金额¥X，按公司阈值属"极小"级别（< ¥10,000） |
| C2 | 基本可承受 | 采购金额属"中"级别，需确认当月采购计划 | 承受性：基本可承受｜本次采购金额¥X，建议确认当月采购计划 |
| C3 | 偏紧 | 采购金额属"大"级别，可能压缩其他采购 | 承受性：偏紧｜本次采购金额¥X，可能压缩其他重要采购安排 |
| C4 | 不可承受 | 采购金额属"重大"级别，需升级确认 | 承受性：不可承受｜本次采购金额¥X，需财务负责人确认 |
| C5 | 无法判断 | 缺少资金计划信息 | 承受性：无法判断｜缺少可用现金余额和资金计划 |

**采购金额大小的标准化**（与 v1.2 标准 §4.5 一致）：

| 级别 | 绝对值范围 | 典型业务含义 |
|-|-|-|
| 极小 | < ¥10,000 | 无需特别关注承受性 |
| 小 | ¥10,000 - ¥50,000 | 月度预算内通常可覆盖 |
| 中 | ¥50,000 - ¥200,000 | 需确认当月采购计划 |
| 大 | ¥200,000 - ¥500,000 | 需财务负责人确认 |
| 重大 | > ¥500,000 | 需升级管理层审批 |

### 4.6 证据集中管理

与 v1.2 标准 §4.6 一致。同一证据点可以影响多个判断，但应先集中列在「关键证据/异常点」中，再由五项判断分别解释影响。

**采购场景的证据一因多果示例**：

| 证据点 | 可能影响 | 处理方式 |
|-|-|-|
| 物品单价偏离历史均价 > 30% | 主要影响价值性，也影响真实性和必要性 | 作为主判定优先处理 |
| 附件缺少单价和数量明细 | 影响真实性和价值性 | 标注为信息缺口，条件通过中要求补充 |
| 供应商为临时合格供应商 | 影响合规性和真实性 | 标注为非标准情形，评估实际渠道可靠性 |
| 首次采购该物品 | 影响价值性（无基准） | 标注为首次采购，建议建立价格基准 |

## 五、综合建议动作生成标准

### 5.1 建议动作类型

| 建议动作 | 适用条件 |
|-|-|
| **通过** | 所有判断项支撑充分，供应商可靠，价格与历史一致或在阈值内 |
| **条件通过** | 核心判断通过，但存在价格偏离、信息缺口等可控风险，必须附加可关闭的条件 |
| **驳回补材料** | 缺少采购明细附件或关键信息，无法形成可靠判断 |
| **暂缓** | 当前不适合采购（如项目未启动、预算未批），未来满足条件后可重新判断 |
| **不通过** | 供应商未准入、价格严重偏离且无合理解释、采购无必要性 |
| **升级确认** | 价格偏离 > 50% 或供应商异常，需要采购部门或管理层专项确认 |

### 5.2 「条件通过」的强制规范

每项条件必须包含四要素：

| 要素 | 说明 | 正确示例 | 错误示例 |
|-|-|-|-|
| 条件内容 | 具体要完成什么 | 「确认文件盒单价¥92.02的比价依据」 | 「完善采购信息」 |
| 责任人 | 指定到岗位或姓名 | 「申请人/贾梦蕾」 | 「相关人员」 |
| 截止时间 | 具体天数或日期 | 「5个工作日」 | 「尽快」 |
| 逾期处理 | 未完成怎么办 | 「逾期未补充则暂缓审批对应物品」 | （缺失） |

### 5.3 综合建议生成规则

1. **价格偏离是否超阈值？** → 超 50% → 不通过/升级确认
2. **附件信息是否完整？** → 不完整 → 驳回补材料/条件通过
3. **供应商是否准入？** → 未准入 → 不通过
4. **多数项充分，价格偏离 30%-50%？** → 是 → 条件通过（要求确认比价）
5. **所有项充分且价格一致？** → 是 → 通过

## 六、建议信心标准

建议信心衡量 Agent 对当前建议动作的把握。信息不足时，如果建议是「补材料」且缺口明确，建议信心可以较高；如果建议是「通过」但关键项支撑不足，建议信心必须降低。

| 场景 | 建议动作 | 建议信心 |
|-|-|-|
| 全部物品单价与历史一致，供应商可靠，信息完整 | 通过 | 高 |
| 核心判断通过，但部分物品首次采购或轻微偏离 | 通过/条件通过 | 中高 |
| 总金额一致但缺少单价明细，或部分物品偏离 30%+ | 条件通过 | 中 |
| 供应商为新供应商，无历史参照，信息不充分 | 条件通过/升级确认 | 中低 |

建议信心使用「高 / 中 / 低」或「中高 / 中低」表达，并附信心来源说明。

## 八、Agent 边界与人工判断的交接标准

### 8.1 Agent 负责

- 采购明细 Excel 解析和逐项提取
- 合格供应商库加载和供应商精确匹配（优先判定）
- 预建数据表查询（物料均价速查表 + 供应商主表 + 物料价格历史表）
- 价格偏离度自动计算
- 五项判断的初步评级
- 建议方案生成

### 8.2 必须移交人工判断的情形

| 情形 | 移交对象 |
|-|-|
| 价格偏离 > 50% 且无合理解释 | 采购部门 |
| 供应商未在公司准入名单中 | 采购部门 |
| 采购金额属"重大"级别（> ¥500,000） | 管理层 |
| 同一物品短期内反复采购（异常频次） | 采购部门 |
| 采购类型与业务用途明显不匹配 | 部门负责人 |
